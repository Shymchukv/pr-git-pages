Практична робота 1.2: Git та GitHub Pages

Виконав: Шимчук Владислав | Група: 1 КТ 23

Теорія

1. Інформація про СКВ та Git

Система контролю версій (СКВ / VCS) — це спеціальне програмне забезпечення, призначене для збереження історії змін у файлах проєкту. Вона дає змогу повертатися до попередніх версій коду, відстежувати авторів правок та безпечно працювати над проєктом у команді.

Git — це найпопулярніша розподілена система контролю версій, створена Лінусом Торвальдсом у 2005 році. На відміну від централізованих систем, кожен розробник зберігає повну копію всього репозиторію на власному комп'ютері.

Переваги

2. Основні можливості та переваги Git

  • Автономність: Більшість операцій (коміти, перегляд історії, створення гілок) виконуються локально без доступу до мережі.
  • Гнучке гілкування (Branching): Легке створення ізольованих гілок для розробки нових функцій та їх зручне об'єднання (Merge).
  • Висока швидкість: Операції локального збереження відбуваються миттєво.
  • Цілісність даних: Усі коміти хешуються (алгоритмом SHA), що унеможливлює непомітну зміну історії.
Команди

3. 10 Базових команд Git

Команда Опис та коментар
git initСтворення нового порожнього локального репозиторію.
git clone <url>Копіювання існуючого віддаленого репозиторію на комп'ютер.
git statusПеревірка стану відстежуваних, змінених та нових файлів.
git add .Додавання всіх змінених файлів до зони підготовки (Staging Area).
git commit -m "msg"Фіксація збережених змін із описовим коментарем.
git branchПерегляд списку існуючих локальних гілок.
git checkout -b <name>Створення нової гілки та автоматичний перехід на неї.
git merge <branch>Об'єднання вказаної гілки з поточною активною гілкою.
git pullОтримання останніх змін із віддаленого сервера та їх злиття.
git push origin mainНадсилання локальних комітів у віддалений репозиторій на GitHub.
