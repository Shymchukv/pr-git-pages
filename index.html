1. Що таке СКВ та Git

Система контролю версій (СКВ / VCS) — це спеціалізоване програмне забезпечення для фіксації та керування змінами в сирцовому коді. Вона дозволяє відмотувати проєкт до будь-якої точки в минулому та працювати в команді без ризику перезаписати чужий код.

Git — це розподілена система контролю версій нового покоління, створена Лінусом Торвальдсом. У Git кожен розробник володіє повноцінною локальною копією всієї історії репозиторію.

2. Основні можливості та переваги

Миттєва швидкість

Майже всі операції виконуються локально на вашому ПК без затримок мережі.

Гнучке гілкування

Створення ізольованих гілок для фіч та їх швидке об'єднання (Merge).

Надійність даних

Історія захищена контролями цілісності за допомогою хешування SHA.

Автономність

Повноцінна робота з кодом та історією без підключення до Інтернету.

3. 10 Базових команд Git

bash — git-cli
git init # Ініціалізація нового локального репозиторію
git clone <url> # Клонування віддаленого репозиторію на ПК
git status # Перевірка стану змінених та нових файлів
git add . # Додавання всіх файлів до зони підготовки (Staging)
git commit -m "msg" # Фіксація підготовлених змін із коментарем
git branch # Перегляд списку існуючих локальних гілок
git checkout -b <name> # Створення нової гілки та перехід на неї
git merge <branch> # Злиття вказаної гілки з поточною
git pull # Завантаження та злиття змін із сервера
git push origin main # Відправка локальних комітів на GitHub
